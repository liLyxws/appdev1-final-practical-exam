# APPDEV1 Final Practical Exam

A React.js (Vite) project that converts a Figma design into Sign Up and Login pages, using CSS Modules, design tokens in root.css, and the shadcn/ui Input component.

## Reflection

### What I did

I created the Sign Up and Login pages based on the Figma design. I used React.js, CSS Modules, and root.css to organize the design and styles. I also set up Tailwind CSS and used the shadcn/ui Input component for the text fields.

### What I learned

I learned how CSS Modules help organize styles for each component. I also learned how design tokens make reusable styles easier to manage and how shadcn/ui components can be used in a React project.

### Challenges I faced

One of the challenges I faced was setting up Tailwind CSS and shadcn/ui correctly. I also had to check the layout and spacing to make the pages match the Figma design. I solved these problems by following the setup steps and checking the results in the browser.

### What I would improve

If I had more time, I would improve the responsiveness of the pages on different screen sizes. I would also review the spacing and details again to make the design closer to the Figma reference.
